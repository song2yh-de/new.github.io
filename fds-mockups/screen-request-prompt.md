# 프롬프트 예시 — FDS 수진자 검사결과 조회 화면

> 사용법: `design.md`, `design-corrections.md` 두 파일을 첨부하고 아래 텍스트를 그대로(또는 필요한 부분만 수정해서) 프롬프트로 보내면 됩니다.

---

첨부한 `design.md`(디자인 시스템 스펙)와 `design-corrections.md`(정정사항·구현 규칙)를 기준으로, 아래 내용의 화면을 HTML 아티팩트로 만들어줘. 색상·간격·컴포넌트 분류는 전부 두 문서 기준을 따르고, 임의로 새 값을 만들지 말고 문서에 없는 부분만 물어봐줘.

## 화면 개요
- 화면명: 수진자 검사결과 조회
- GNB: 롯데카드 FDS 로고, 메뉴(운영관리/모니터링/실적현황(활성)/CASE관리/리스트/정보유출/코드), 우측 유틸 아이콘 묶음 + 사용자명 + 세션 시계
- page-tab: Home / 메세지처리이력(활성) / 사고현황분석

## 레이아웃 구조 (design-corrections.md 8번 규칙 적용)
- 좌측 = 메인 화면: 검색영역 + 수진자 목록, 카드 없이 흰 배경에 그대로 배치
- 우측 = 서브 화면: 검사결과, 회색 배경(풀블리드, 라운드 없음) 위에 흰 카드(그림자)로 표현
- 좌우는 갭 없이 맞닿아서 화면이 면분할된 것처럼 보이게

## 좌측: 검색영역 + 수진자 목록
1. "검색영역" 타이틀 + 우측에 "상세검색" 토글(버튼, 클릭 시 검색박스가 늘어나며 아래 필드 추가 노출)
   - 기본 노출 필드: 기간(select: 접수일자/보고일자 + 전체/1일/3일/1주일/1개월/3개월 버튼그룹), 날짜범위 + 검사진행(select), 수진자명 + 차트번호(input)
   - 상세검색 펼침 시 추가 필드: 생년월일(input), 검체번호(input), 항목명(select[전체]), 검사분야(select[전체]), 검체구분(체크박스: 일반/조직/세포) + COVID19(select[전체])
   - 조회(button/search 토큰) / 초기화(button/default 토큰) 버튼
2. "수진자 목록" 서브타이틀 + grid(design-corrections.md 1번 기준 grid 분류)
   - 컬럼: 접수일자 / 차트번호 / 수진자 / 성별 / 나이 / 검체번호 / 이전결과(아이콘) / 상태(변동 아이콘) / 검사진행(chip)
   - 검사진행 chip: 검사중=브랜드 chip, 완료=회색 chip (design-corrections.md 6번)
   - 샘플 데이터 12~15행, 그 중 1행은 선택된 상태로 표시

## 우측: 검사결과 (서브 화면)
1. "검사결과" 타이틀 + 액션 버튼 그룹
   - 검사결과이력조회 / 결과지출력 / 추가검사 / 오더의뢰지 = 전부 button/default
   - 엑셀결과받기 = 맨 우측에 배치, button/icon 토큰의 아이콘 전용 버튼(텍스트 없음)
2. 수진자 정보 요약 — table 분류(design-corrections.md 1번), 라벨:값 그리드
   - 항목: 수진자 / 차트번호 / 접수일자 / 주민등록번호 / 담당의·과·병동 / 성별 / 나이 / 검체종류 / 검체번호 / 의료기관 / 병원코드 / 접수번호 / 실거주지
3. "검사결과 상세" 서브타이틀 + grid
   - 컬럼: 체크박스 / 보험코드 / 검사항목 / 결과 / 참고치 / H/L / 보고일자 / 이전결과(아이콘)
   - 일반 혈액검사 항목 샘플 데이터 12~15행 (정상/이상(H)/낮음(L) 값 섞어서)

## 필수 준수 사항
- Table/Grid 토큰 분류, 네이밍(header/border, bg-group 등), spacing(타이틀-콘텐츠 8px, heading 기본 마진 리셋) 전부 design-corrections.md 기준 그대로
- 폰트는 NanumSquare Neo 대신 Noto Sans KR로 대체
- 완성 후 색상/간격은 눈대중하지 말고 실제 렌더링 픽셀 샘플링 + DOM 실측으로 검증(design-corrections.md 12번)

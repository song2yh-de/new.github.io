레이아웃 패턴

새 화면을 만들 때 이 중 화면 성격에 맞는 걸 고른다. 좌/우 2분할이 아닌 새 패턴이 필요하면 components.css에 클래스를 추가하고, 화면 파일 안에서 인라인으로 새로 짜지 않는다.

.grid2 — 메인(좌, 카드없음) + 서브(우, 회색풀블리드+흰카드) · 목록→상세 흐름

예: fds-screen.html (수진자검사결과 조회). template.html 참고.

.dash-layout > .dash-main(카드 여러 개 세로) + .dash-side(고정폭, 선구분, 화면 끝까지 항상 떠있음)

예: merchant-info-screen.html / cash-advance-screen.html의 배분영역(실시간 모니터링).

.cardrow — 밀도 높은 다중 패널 대시보드 (정보 조회형)

위 "카드" 섹션 예시 참고.

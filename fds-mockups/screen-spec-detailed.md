# 화면정의서 — 수진자 검사결과 조회 (FDS)

> 사용법: `design.md` + `design-corrections.md`와 함께 이 문서를 통째로 첨부하고 "이 화면정의서대로 만들어줘"라고 요청하면 됩니다.
> 이 문서 자체가 기획 단계 산출물(화면정의서) 용도로도 재사용 가능하도록, 실제 노출되는 문구·옵션값·샘플 데이터까지 전부 명시했습니다.

---

## 0. 화면 개요

| 항목 | 내용 |
|---|---|
| 화면명 | 수진자 검사결과 조회 |
| 상위 메뉴 경로 | 실적현황 > 메세지처리이력 |
| 목적 | 수진자를 검색·목록 조회하고, 목록에서 선택한 수진자의 검사결과 상세를 우측에서 확인 |
| 핵심 흐름 | 좌측 수진자 목록에서 row 선택 → 우측 검사결과 서브화면에 해당 수진자 결과 표시 |

---

## 1. 레이아웃 구조

```
┌ GNB ─────────────────────────────────────────────────────────┐
├ Page-tab (Home / 메세지처리이력 / 사고현황분석) ──────────────┤
├ 좌측: 메인 화면(흰 배경, 카드 없음) ─┬ 우측: 서브 화면(회색 풀블리드+흰 카드)─┤
│  검색영역                            │  검사결과                              │
│  수진자 목록 (grid)                  │  수진자 정보 요약 (table)              │
│                                       │  검사결과 상세 (grid)                  │
└───────────────────────────────────────┴─────────────────────────────────────┘
```

design-corrections.md 8번 규칙(메인/서브 화면 분리 패턴) 적용.

## 4. 좌측 영역 — 검색영역 + 수진자 목록

### 4.1 검색영역 타이틀 줄
- 타이틀: "검색영역"
- 우측: "상세검색" 토글(버튼). 클릭 시 검색박스가 확장되며 4.3 필드 노출. 쉐브론 아이콘 180도 회전으로 열림/닫힘 표시.

### 4.2 기본 노출 필드

| 필드 라벨 | 컴포넌트 | 옵션 / 기본값 |
|---|---|---|
| 기간 | select | 접수일자(기본) / 보고일자 |
| (기간 단축 버튼그룹) | segmented button | 전체(기본 선택) / 1일 / 3일 / 1주일 / 1개월 / 3개월 |
| 날짜 | date input 2개 | from: 2026-05-01, to: 2026-05-31 |
| 검사진행 | select | 전체(기본) / 검사중 / 완료 |
| 수진자명 | text input | placeholder: 수진자명 |
| 차트번호 | text input | placeholder: 차트번호 (라벨은 "수진자명"으로 표기되어 있으나 실제 값은 차트번호 — 라벨 확정 필요 시 확인) |

버튼: **조회**(button/search 토큰, 강조) / **초기화**(button/default 토큰)

### 4.3 상세검색 펼침 필드 (기본 숨김)

## 7. 준수 규칙 (design-corrections.md 요약 참조)

- 컴포넌트 분류: 수진자 목록/검사결과 상세=grid, 수진자 정보 요약=table
- 색상 토큰: chip(검사중=brand, 완료=gray), button/search(조회), button/default(액션그룹), button/icon(엑셀)
- 레이아웃: 좌측 메인 화면(카드 없음) / 우측 서브 화면(회색 풀블리드+흰 카드)
- spacing: 타이틀-콘텐츠 8px, heading 기본 마진 리셋 필수
- 폰트: Noto Sans KR (NanumSquare Neo 대체)
- 완성 후 픽셀/DOM 실측 검증
